# ADR 0000: Registro Retroativo de Decisões

**Data:** 2026-03

## Contexto

O projeto backend evoluiu desde sua concepção em 2021 sem o uso sistemático de ADRs (Architecture Decision Records). Muitas decisões cruciais ficaram registradas apenas no histórico de commits ou implicitamente no código e na mente dos desenvolvedores. Os desenvolvedores já utilizavam o formato no frontend, porém o backend acabou esquecido.

## Decisão

Registrar ADRs a partir de 2026, documentando, inclusive de forma retroativa, as principais decisões técnicas tomadas ao longo da evolução desta API.

## Consequências

O histórico técnico e as motivações da API serão preservados, facilitando o onboarding. Além disso, padronizamos as documentações do frontend e do backend, embora algumas informações de contexto mais antigas possam estar incompletas.
